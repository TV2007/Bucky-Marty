# Webcomic Site — Project Context

This is a static webcomic site template for a web design course. No backend, no build step —
just HTML/CSS/vanilla JS served as flat files, deployed via GitHub Pages.

## The Brain: manifest.json

`manifest.json` is auto-generated by `scan.js` and lists every series/chapter/page. It is never
hand-edited in normal use — `node scan.js` reads the `comics/` folder tree and regenerates it,
plus `sitemap.xml`. (If Node.js isn't installed on this machine, manifest.json can be hand-edited
to match the shape `scan.js` would produce — see the schema below — but prefer running the real
scanner once Node is available.)

## File structure

```
index.html / about.html / series.html / reader.html / archive.html / 404.html
scan.js            — the scanner, run after any content change
manifest.json      — auto-generated, don't hand-edit if Node is available
robots.txt, .nojekyll
css/style.css       — all styling, theme variants via body[data-theme]
js/app.js           — homepage (series grid + updates feed)
js/series.js        — series page (chapter list)
js/reader.js        — reader (navigation, swipe, zoom, keyboard shortcuts, progress)
js/archive.js       — archive page (all chapters, all series)
assets/             — site-wide: logo.png, artist.png, favicon.ico
comics/<slug>/series.json, assets/{cover,header,bg,bg-pause}.*, <chapter-slug>/{chapter.json, 01.jpg, 02.jpg, ...}
```

## manifest.json schema (what scan.js writes)

```json
{
  "generatedAt": "ISO timestamp",
  "series": [
    {
      "slug": "folder-name",
      "title": "...", "shortName": "...", "description": "...",
      "accentColor": "#hex", "theme": null | "warm" | "cool" | "dark" | "sepia",
      "backgroundMode": "cover" | "tile",
      "cover": "cover.jpg" | null, "header": "header.png" | null,
      "bg": "bg.jpg" | null, "bgPause": "bg-pause.jpg" | null,
      "chapters": [
        { "slug": "chapter-01", "title": "...", "date": "YYYY-MM-DD" | null,
          "pages": ["01.jpg", "02.jpg", ...], "bg": "bg.jpg" | null }
      ]
    }
  ]
}
```

## Key rules

- Series/chapter folder names are URL slugs (`?s=slug`, `?ch=slug`) — lowercase, hyphenated.
- Page filenames must be zero-padded (`01.jpg` not `1.jpg`) or sort order breaks after page 9.
- A chapter with zero image files is dropped from the manifest by the scanner.
- `scan.js`'s `BASE_URL` constant and `robots.txt`'s `Sitemap:` line must both be updated to the
  real GitHub Pages URL before going live — they're currently placeholders.

## Intentionally kept simple

- No framework, no bundler, no CSS preprocessor — this is deliberate for a student project.
- No image optimization pipeline — the guide instructs manual export settings (JPG, 70–80%, sRGB).
- `localStorage` is used for reading-progress only; no accounts, no server state.
